# Life Dashboard 🌟

Proyek ini dibuat sebagai tugas akhir **CodingCamp batch 19 Oktober 2026**.

## Tentang Proyek

**Life Dashboard** adalah aplikasi web sederhana yang membantu pengguna mengatur hari mereka dalam satu halaman. Dibangun menggunakan HTML, CSS, dan Vanilla JavaScript murni tanpa framework.

## Fitur

- ⏰ **Jam & Greeting** — Jam real-time dengan sapaan berdasarkan waktu
- ✏️ **Nama & Foto Profil** — Custom nama dan upload foto profil
- 🌤️ **Widget Cuaca** — Cuaca lokal otomatis via geolocation
- 💪 **Kutipan Motivasi** — Berganti setiap hari
- ❄️ **Efek Salju** — Animasi salju di background (bisa toggle)
- ⏱️ **Focus Timer** — Pomodoro timer dengan ring progress
- ✅ **To-Do List** — Tambah, edit, centang, hapus tugas
- 📝 **Catatan Cepat** — Auto-save ke localStorage
- 🎵 **Music Player** — Playlist YouTube & SoundCloud
- 🔗 **Quick Links** — Pintasan ke website favorit
- 🌙 **Light / Dark Mode** — Toggle tema

## Teknologi

- **HTML5** — Struktur halaman
- **CSS3** — Styling (Pure CSS, tanpa framework)
- **Vanilla JavaScript** — Logika aplikasi
- **localStorage** — Penyimpanan data lokal

## Cara Menjalankan

Cukup buka file `index.html` di browser. Tidak perlu server atau instalasi apapun.
